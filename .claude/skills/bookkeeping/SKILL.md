# Bookkeeping

## 项目定位

Bookkeeping 是一个长期维护的个人记账项目。

- 个人开发，5～20 人使用
- 移动端（iOS + Android），自建后端
- 支持云同步，后续支持 AI 能力

本项目不是大型企业系统。所有技术决策遵循以下优先级：

```
简单 > 可维护 > 稳定 > 性能 > 扩展性
```

如果存在多个可行方案，应默认选择最简单的一种。

---

# 开发原则

1. **官方优先** — 除非存在明显收益，否则不引入社区替代方案。
2. **保持简单** — 一个问题只允许一种解决方案，避免技术栈重复。
3. **复用优先** — 开发前检查是否已有模块、Schema、Service、组件可复用。
4. **类型优先** — 所有数据结构先定义 Schema，再推导 Type。
5. **AI 可插拔** — AI 是基础能力，业务代码不得依赖具体模型，切换模型仅改配置。

# 工作流程

处理任何开发任务时，遵循以下流程：

```
理解需求 → 读取对应 Skill → 检查是否已有实现 → 设计方案 → 生成代码 → 检查是否符合项目规范
```

不要直接开始写代码。

# 最终要求

- 优先简单，而不是复杂。
- 优先复用，而不是重复开发。
- 优先官方方案，而不是社区方案。
- 优先可维护，而不是过度优化。
- 优先解决当前问题，而不是未来问题。

如本 Skill 与其它 Skill 存在冲突，以本 Skill 为准。
